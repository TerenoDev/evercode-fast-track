# Tests Documentation

## Как запустить тесты

```bash
npm test
```

Тесты используют базу данных в памяти (:memory:), что изолирует их от рабочей БД.

## Результат запуска

```bash

PASS  src/tests/coins.test.ts (10.767 s)
Test Suites: 2 passed, 2 total
Tests:       15 passed, 15 total
Snapshots:   0 total
Time:        13.67 s
```

## Что не покрыто тестами (осознанно)
- Реальные запросы к CoinMarketCap API - не тестируются, чтобы не зависеть от интернета и лимитов. Вместо этого проверяется корректная обработка ошибок (404, 502).
- Фоновый планировщик - тестируется косвенно через проверку работы сервиса TaskScheduler при ручном запуске (логи в консоли).
- Graceful Shutdown - проверяется вручную при нажатии Ctrl+C.

## Технологии
- Jest - фреймворк для тестирования.
- Supertest - для E2E-тестирования HTTP-эндпоинтов.
- ts-jest - для запуска TypeScript-тестов без предварительной компиляции.
